# Diabetes-Predictor-Neural-Network
In this project, we aim to build a simple neural network to predict the likelihood of an individual having diabetes based on a synthetic dataset of health-related features.

You have a synthetic dataset containing information about individuals, including features like age, BMI, blood pressure, and more. The target variable is 'Outcome', which indicates whether the individual has diabetes (1) or not (0). This develops a basic neural network from scratch to perform binary classification.
